# Agent 系统工具能力全景

本文档记录 GitHub Stars 管理系统暴露给 AI Agent 的完整 MCP 工具集。

## 架构

```
用户提问 → AgentController → AgentClientService.stream()
                                    │
                                    ├─ mcpServers.github (@modelcontextprotocol/server-github)
                                    │   └─ GitHub 公开数据查询
                                    │
                                    └─ mcpServers.system (createSystemMcpServer)
                                        └─ 本系统业务 API（57 个工具）
```

## 工具清单（按领域）

### 1. Stars 星标仓库（7 个工具）
| 工具名 | 说明 |
|--------|------|
| `stars_list` | 分页查询星标仓库，支持关键词/语言/日期/翻译状态筛选 |
| `stars_detail` | 获取单个仓库完整详情（含 README、分类、翻译） |
| `stars_star` | 在 GitHub 上 Star 指定仓库 |
| `stars_unstar` | 取消 Star 指定仓库 |
| `stars_check_starred` | 检查指定仓库是否已 Star |
| `stars_ids` | 按筛选条件获取所有仓库 ID（用于批量操作） |
| `stars_by_ids` | 根据 ID 列表批量获取仓库详情 |

### 2. Category 分类管理（10 个工具）
| 工具名 | 说明 |
|--------|------|
| `category_tree` | 获取完整分类树（两级结构） |
| `category_list` | 分页获取一级分类列表 |
| `category_create` | 创建新分类（支持子分类） |
| `category_update` | 更新分类信息 |
| `category_delete` | 删除分类 |
| `category_sort` | 批量更新分类排序 |
| `category_repos` | 查询分类下的仓库列表 |
| `category_bind` | 批量绑定仓库到分类 |
| `category_unbind` | 批量解绑仓库从分类 |
| `category_batch_ids` | 获取分类下所有仓库 ID |

### 3. Stats 统计分析（6 个工具）
| 工具名 | 说明 |
|--------|------|
| `stats_languages` | 编程语言分布统计 |
| `stats_owners` | 仓库所有者排名 |
| `stats_timeline` | Star 时间线统计 |
| `stats_overview` | 整体概览（总数/Star/Fork/语言数） |
| `stats_top_starred` | Star 数量排行榜 |
| `stats_recent_active` | 最近活跃仓库 |

### 4. Clone 克隆（8 个工具）
| 工具名 | 说明 |
|--------|------|
| `clone_create` | 创建 Git 克隆任务 |
| `clone_tasks_list` | 克隆任务列表 |
| `clone_directories` | 常用目录列表 |
| `clone_task_detail` | 克隆任务详情 |
| `clone_task_retry` | 重试失败项 |
| `clone_task_reset` | 重置任务 |
| `clone_task_retry_item` | 重试单个失败项 |
| `clone_task_delete` | 删除任务 |

### 5. Download 下载（13 个工具）
| 工具名 | 说明 |
|--------|------|
| `download_create` | 创建下载任务 |
| `download_tasks_list` | 下载任务列表 |
| `download_directories` | 常用目录列表 |
| `download_task_detail` | 下载任务详情 |
| `download_estimate_sizes` | 预估下载大小 |
| `download_task_retry` | 重试失败项 |
| `download_task_reset` | 重置任务 |
| `download_task_retry_item` | 重试单个失败项 |
| `download_task_delete` | 删除任务 |
| `download_task_extract` | 解压单个仓库 |
| `download_task_delete_item` | 删除单个压缩包 |
| `download_task_extract_all` | 一键解压全部 |
| `download_task_extract_progress` | 查询解压进度 |

### 6. Sync 同步（3 个工具）
| 工具名 | 说明 |
|--------|------|
| `sync_manual` | 手动触发 Star 数据同步 |
| `sync_status` | 获取同步状态 |
| `sync_logs` | 查看同步日志 |

### 7. Trending 趋势（1 个工具）
| 工具名 | 说明 |
|--------|------|
| `trending_list` | 获取 GitHub Trending 仓库 |

### 8. Author 作者中心（3 个工具）
| 工具名 | 说明 |
|--------|------|
| `author_list` | 作者列表 |
| `author_repos` | 作者仓库 |
| `author_export_urls` | 导出作者仓库 URL |

### 9. Config 系统配置（2 个工具）
| 工具名 | 说明 |
|--------|------|
| `config_list` | 获取系统配置（敏感字段脱敏） |
| `config_update` | 批量更新系统配置 |

### 10. Export 导出（1 个工具）
| 工具名 | 说明 |
|--------|------|
| `export_markdown` | 导出仓库列表为 Markdown |

### 11. Logging 日志（3 个工具）
| 工具名 | 说明 |
|--------|------|
| `logs_files` | 日志文件列表 |
| `logs_view` | 查看日志内容 |
| `logs_clear` | 清空日志文件 |

**总计：57 个工具**
